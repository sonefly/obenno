# assets/gallery

图录页（/gallery.html）所用六帧示意图像的存放目录。

- 均由 AI 生成，经统一调色与压缩，960×1200，JPEG（q84），单张约 80–130 KB；
- 文件名为拼音序号：01-xiangzhuan（香篆）、02-dengming（灯明）、03-fanzhong（梵钟）、04-jingjuan（经卷）、05-lianhua（莲华）、06-putiye（菩提叶）；
- 非文物摄影，不作造像形制依据；换图时请同时更新 gallery.html 中的 alt、尺寸与 og:image；
- 本目录不放视频。图录页的动态全部由 CSS 实现（极缓推近 + 光气微动，见 gallery.html 内联样式 gaKBa–gaKBd / gaHaze / gaGlow / gaShaft / gaWater），不依赖 mp4；系统开启「减少动态效果」时自动静止。
