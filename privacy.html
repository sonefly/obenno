隐私与 Cookie Privacy

不登录、不画像、不投放广告；能关的开关都关着。

本站不收集什么

不设账号体系，不收集姓名、邮箱、电话、地址与支付信息；不登录即可读全部正文；不做用户画像，不做广告投放，不向第三方出售或共享个人数据。

存在你浏览器里的数据

为记住阅读偏好与功课进度，本站使用浏览器 localStorage（不是 Cookie）。数据只留在本机，不上传服务器，键名统一以 fxy- 开头：

fxy-lang界面语言偏好（中文 / 英文对照）
fxy-sutra-zoom
fxy-cs-zoom		经文页与抄经页的字号缩放
fxy-py拼音注音的显示开关
fxy-today 等今日佛号数、功课进度、供灯与供水记录，只用于当日显示
fxy-pos-<经号>上次读到哪一节，便于回到原处

清除方式：在浏览器设置里清除本站的「站点数据 / 本地存储」即可，之后一切从零开始，不影响阅读与检索。

访问统计

本站使用 Microsoft Clarity 做匿名访问统计（站点 ID zh32wbcuxz），用于了解哪些页面常被阅读、何处出现卡顿。Clarity 会写入统计用 Cookie，并收集匿名的浏览行为（页面、点击、滚动、设备类型、大致地区）。本站不向其传任何表单内容：页面除检索框外没有输入控件，检索只在你的浏览器内完成。

  • 拒绝方式：开启「请勿追踪 / Do Not Track」、使用隐私模式、安装广告拦截扩展，或直接屏蔽 clarity.ms 域名——本站功能不受影响。
  • 本站不使用 Google Analytics，不接入广告、再营销或社交平台追踪像素。

到访问候计数

首页的问候语与「善信第 N 次入殿」由本站自建的一个计数服务给出，不经任何第三方定位接口，也不做跨站追踪：

收集IP 地址的短时哈希（仅供单次访问去重，两日后丢弃，不存原 IP）；粗略位置（省/州与城市级，国家仅作归类）；User-Agent 的粗粒度归类
用途只用于生成问候语中的地名与到访人次，不用于画像、不与其他数据关联
频次同一浏览器每日只计一次；服务不可达时，问候语回落为默认文案
拒绝屏蔽该请求或使用拦截扩展即可，问候语回落，站内阅读与功课功能不受影响

第三方请求

  • 字体、样式、脚本、经文 JSON 与音频全部由本站域名提供，不调用 Google Fonts 等外部字体服务。
  • 托管方 GitHub Pages 与前置的 Cloudflare 会在其自身日志中记录访问所需的 IP、时间与 User-Agent，用于传输与防护。这部分日志由服务商按其隐私政策处理，本站不另存、不做关联分析。
  • 页面内不嵌入第三方视频、地图或评论组件。

儿童与跨境

本站内容为公开的佛教典籍与常识，未针对儿童设计任何收集行为，也不主动获取年龄信息。因无账号、无个人数据上传，跨境问题仅涉及上述服务商的访问日志。

变更与联系

若统计工具或本机存储用途发生变化，会在本页更新并注明日期；历史版本可在仓库提交记录中查对。隐私相关问题请在 github.com/sonefly/obenno/issues 提出，或写信至 hello@obenno.com（域名邮箱，2026 年 11 月 23 日起实测收信正常；来信一般在七日内答复，邮件仅由维护者本人阅读，不用于任何统计或营销）。
